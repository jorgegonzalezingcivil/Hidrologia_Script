# Dependencias del venv del proyecto (CLAUDE.md, sección 3).
#
# El paquete src/comun (M00) se limita de forma deliberada a la librería
# estándar más PyYAML, que el Python de QGIS ya incluye. Esa restricción es la
# que permite que los módulos SIG y los de análisis compartan una sola
# implementación de configuración, rutas y logging.
#
# Las dependencias de los módulos de análisis se agregan a medida que cada uno
# se programa, no antes.

pyyaml==6.0.2

# --- Cálculo numérico y estadístico -----------------------------------------
# Solo para los módulos de análisis. El paquete src/comun NO puede importarlos:
# lo comparte el Python de QGIS, y hacerlo rompería el esquema de doble entorno.
#
# Los pide el análisis de frecuencia del M07, que CLAUDE.md, sección 6, cierra
# con nueve distribuciones (Normal, LogNormal 2/3P, Gumbel, GEV, Pearson III,
# Log-Pearson III, Exponencial, Weibull, Gamma), tres métodos de ajuste
# (momentos, momentos-L y máxima verosimilitud) y las pruebas KS,
# Anderson-Darling y chi-cuadrado con AIC/BIC. Programar el ajuste por máxima
# verosimilitud de la GEV con librería estándar es posible y desaconsejable.
#
# También los usan el complemento de series del M05 y el balance del M18.
numpy==2.5.1
scipy==1.18.0

# --- Graficación -------------------------------------------------------------
# La consume src/graficos.py, punto único de estilo de las figuras. CLAUDE.md no
# asignaba su generación a ningún módulo: 'informe' define cómo el M15 las numera
# y rotula, y 'cartografia' corresponde al M16, que son mapas.
#
# Tampoco puede importarla src/comun, por la misma razón que numpy y scipy: el
# Python de QGIS comparte ese paquete. La separación la comprueba
# tests/test_graficos.py.
matplotlib==3.11.1

# --- Reproyección ------------------------------------------------------------
# Las figuras geográficas se rotulan en coordenadas planas, como los mapas del
# informe de referencia, que usa MAGNA Ciudad Bogotá. El venv no tiene QGIS, de
# modo que necesita reproyectar por su cuenta.
#
# Es la misma PROJ que usa QGIS por debajo. Programar la proyección a mano para
# la ocasión no sería defendible ante interventoría. La reproyección sigue
# siendo explícita (CLAUDE.md, sección 5): quien dibuja declara origen y destino.
pyproj==3.7.2

# --- Imputación multivariada -------------------------------------------------
# La consume el M05 para los métodos knn y mice de complemento de series, que
# config.yaml declara en complemento.metodos_evaluados. Los otros tres
# (razon_normal, regresion_vecinas, idw) se resuelven con numpy.
#
# Es la misma librería que usaba la rutina heredada Impute.py. Lo que allí
# faltaba no era la librería sino la validación cruzada, sin la cual ningún
# método puede compararse con otro.
scikit-learn==1.9.0
